# Duo API Scripts for MSPs
These are not official documentation nor are they officially supported by Duo and are not the responsibility of Cisco.

That being said, I am collecting various scripts that an MSP may use to manage their business. 

Several of the scripts ask you to have your API credentials in a virtual environment. 

Add them to your environment by copying and pasting this and filling it in properly:
```
export DUO_PARENT_IKEY='your-parent-integration-key'
export DUO_PARENT_SKEY='your-parent-secret-key'
export DUO_PARENT_HOST='your-parent-api-hostname'
export DUO_ACCOUNTS_IKEY='your-accounts-integration-key'
export DUO_ACCOUNTS_SKEY='your-accounts-secret-key'
export DUO_ACCOUNTS_HOST='your-accounts-api-hostname'
```
